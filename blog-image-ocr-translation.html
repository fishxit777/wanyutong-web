圖片翻譯實務

LINE 圖片 OCR 翻譯：先把字拍清楚，再逐欄核對

OCR 會先從圖片中辨識文字，再交給翻譯流程。它適合減少重新打字，不代表圖片中的每個數字、欄位或警告都一定辨識正確。

本文目錄適合與不適合操作流程拍攝六要點四類必查隱私與權限核對依據

萬語通的圖片 OCR 是付費群組功能。若群組尚未開通，先傳送 @方案 查看正式方案；不要把圖片功能寫成免費版保證提供。

哪些圖片適合先用 OCR

較適合風險較高原因
單欄公告、簡短 SOP、清晰菜單密集表格、手寫字、反光護貝版面與畫質會影響文字切割
字體清楚的班表字很小、欄位交錯的排班表姓名、日期與班別容易對錯欄
一般工作通知藥袋、醫囑、合約、付款資料辨識錯一個數字就可能造成高風險結果
不適合只靠 OCR 決定的內容藥名與劑量、工安警告、金額與帳號、合約條文、人事處分、身分證件及緊急處置，必須回看原圖並由負責人確認。

LINE 圖片翻譯的操作流程

  1. 先確認群組方案與語言

    傳送 @方案 與 @語言，確認圖片 OCR 已開通且翻譯方向正確。

  2. 裁掉不需要的背景

    只保留要辨識的公告或欄位，避免同一張圖出現多份文件。

  3. 把圖片傳入 LINE 群組

    LINE Messaging API 會把圖片事件交給 Bot；實際處理狀態依服務當下回覆為準。

  4. 等待辨識與翻譯結果

    不要在結果尚未完整出現前連續重傳同一張圖。

  5. 逐欄對照原圖

    先看日期、時間、數量、金額、單位、否定詞、警告與專有名詞。

  6. 重要內容請原發布者確認

    若看不清楚或欄位錯位，重新拍照或取得原始電子檔，不要猜測。

平台技術來源：LINE Developers：Receiving messages。

提高辨識率的六個拍攝要點

  • 鏡頭與紙面保持平行，避免梯形變形。
  • 光線均勻，不讓燈光或手機陰影蓋住文字。
  • 文字填滿畫面，但不要裁掉標題、欄名或單位。
  • 一張圖只放一份文件或一個表格區塊。
  • 對焦後再拍，放大仍能看清楚細字。
  • 若是電子檔，優先上傳原圖或清晰截圖，不要翻拍螢幕。

辨識完成後，四類資訊必須逐項檢查

類型常見錯誤核對方式
日期與時間1/7、17、上午／下午混淆對照原圖並改用完整日期格式
數量與單位10、100；kg、g；mm、cm將數字與單位一起朗讀確認
否定與警告「不得」「停止」「未完成」漏字單獨標出禁止與例外條件
姓名與代號人名、機台、料號字元相似回查名冊或原始系統，不靠翻譯猜測

上傳前先處理隱私與群組可見範圍

群組成員可以看到群組裡的圖片與 Bot 回覆。身分證、護照、病歷、完整信用卡號、銀行帳號、客戶名單或未公開合約，不應為了測試而直接傳入一般群組。

能裁切就只保留必要欄位；能使用假資料演練，就不要使用真實客戶資料。更多資料處理方式請見隱私權政策。

## 已證實的產品事實

| 項目 | 對外說法 | 證據 |
|---|---|---|
| 主要入口 | 萬語通目前以 LINE Bot 為主要服務入口 | `11STARS/app.py` 公開指令與 webhook 流程 |
| 免費文字翻譯 | 中文、英文、日文、韓文不限次數；其他支援語言每日 50 則 | `FREE_DAILY_LIMIT = 50`、`FREE_GROUP_UNLIMITED_LANG_FAMILIES = {'ZH','EN','JA','KO'}` |
| 語言範圍 | 公開列出 36 種常用語言；實際可用狀態以 Bot 的 `@支援語言` 為準 | `SUPPORTED_LANGUAGES_TEXT` 與公開指令 |
| 群組雙向翻譯 | 可設定兩種語言，在同一 LINE 群組中翻譯往返訊息 | 正式群組 webhook 與語言設定流程 |
| 群組多語輸出 | 可將同一則訊息翻成群組設定的多種語言；Bot 訊息會顯示給群組全體成員 | 正式多語流程；LINE Developers 群組訊息規則 |
| 付費群組功能 | 依方案提供完整語言、語音、圖片 OCR、摘要、報表、紀錄搜尋／統計及匯出 | `11STARS/app.py` 方案文字、正式方案文件與付款入口 |
| 方案價格 | 月費 NT$99／30 天、半年 NT$499／180 天、一年 NT$799／420 天、尊爵 NT$2500／每群組 | 正式方案文字；最後仍以付款頁顯示為準 |
| 公開指令 | `@新手教學`、`@說明`、`@語言`、`@語言設定`、`@支援語言`、`@方案` | 正式 Bot 指令路由 |

## 必須附帶的限制

- 文字翻譯可能受上下文、專有名詞、代號與句型影響。
- 語音辨識可能受口音、背景噪音與錄音品質影響。
- 圖片 OCR 可能受清晰度、傾斜、反光、字體與版面影響。
- 摘要與報表用於整理，不代表法律、醫療、工安或人事決策的專業覆核。
- 群組 Bot 訊息顯示給群組成員，不能宣稱可依成員身分秘密顯示不同翻譯。
- 功能可用性受方案、群組開通狀態與第三方服務狀態影響。

## 不得使用的說法

- 未附測試樣本、期間與方法的「平均 0.3 秒」速度宣稱。
- 暗示 LINE、Google、DeepL 或政府機關認證萬語通的徽章或文字。
- 虛構客戶、使用人數、成功率、排名或節省比例。
- 把規劃中或隱藏測試功能寫成所有使用者都能使用。
- 把翻譯結果寫成可取代專業翻譯、醫療、法律或工安判斷。

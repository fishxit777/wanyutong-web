## 本次目標

讓 LINE Bot 新手推播、群組說明、官網、web-app／PWA、桌機版與手機版使用同一套產品說法、方案價格與操作影片。

## 正式產品行為

- 雙向翻譯：`@語言設定 繁體中文 印尼文`，設定後直接傳一般文字。
- 群組多語：`@多語 繁體中文 英文 菲律賓語`。
- 主管接著傳一句話後，Bot 同步翻成群組設定的多種語言。
- 全員在同一個 LINE 群組查看同一份多語結果；不是私下依成員顯示不同語言。
- 個人聊天的 `@多語` 是單次多語翻譯，與群組共享結果分開說明。

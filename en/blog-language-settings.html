Two-way translation, multilingual mode and Filipino: first set the language clearly

WanyuTong supports 36 common languages. This description shows how to view the current settings, establish two-way translation, and what all members will actually see when the multi-national group uses the multilingual mode.

The more language settings, the better. For groups with only two languages, it is easiest to use bidirectional translation; if there are more than three nationalities at the same time, use the multilingual mode. List the languages that you can really use first, so that unnecessary translations of every message in the group can be avoided.

First distinguish between two-way translation and multilingual mode

Two-way translation

Suitable for traditional Chinese and a foreign language, such as traditional Chinese and Indonesian. The supervisor inputs Chinese, and the bot is translated into Indonesian; the employee enters the Indonesian language, and the bot translates the traditional Chinese. Messages remain in the same LINE conversation.

multilingual mode

Suitable for the group to have traditional Chinese, English, Filipino and other languages at the same time. After the supervisor enters a sentence, the first designated target will become the reproducible main language first; other languages are viewed one by one by buttons.

Visible range of LINE groupThe message sent by LINE Bot in the group can be seen by all members. After clicking on other languages, the language translation will also be publicly displayed in the same group, not just for the clicker to view it privately. Dynamic translation cache 24 hours, the button will not re-translate or deduct the quota; at present, the bot does not provide the withdrawal of the sent translation or the in-situ acquisition.

How to avoid too many messages in multilingual groups?

  1. Only set the actual class or commonly used language, do not open all languages at once.
  2. Write a short sentence first in the announcement, and only one thing is explained in a message.
  3. The time, place, and quantity should be placed in a fixed position to avoid being ignored in long paragraphs.
  4. to go back to the original bilingual @多語 關閉; To be directly changed to another set of bilinguals, it can be passed on effectively @語言設定 language A language B, automatically closes continuous multilingual after success.
  5. Please reply in a fixed format, such as "received + name" or "unclear + question".

The multilingual mode will not start all translations at first: display the main language that can be copied first, which other language is needed and which button is pressed. The same language of the same original message in the group is disclosed at most once; each member should still use a personal conversation, personalized web page or independent APP when each member only sees the personal language.

After the setting is completed, you must check three things

  • Sent @語言, confirm that the language listed on the screen is the same as expected.
  • Test with short sentences containing time and quantity, such as "Tomorrow, please bring two pairs of gloves".
  • Ask an employee to reply in his own language to confirm that the supervisor can understand the traditional Chinese that is turned back.

Complete the test in two languages first

First run a set of two-way translation smoothly, and then add language according to the actual group members. The free version does not count the daily quota when the original text and all designated targets belong to both Chinese, English, Japan and South Korea; when the original text or any designated target exceeds the four languages, each original message is calculated. 1 then, daily 50 then. For example, the original Indonesian text is only translated into English and Japanese, and it is still considered 1 Then; the same sentence is translated into three non-four languages, and it is only counted 1 then. The pure URLs, symbols or emojis of the general chat of the group do not automatically translate and deduct this amount; "Good morning" and "Hello" will still be processed.
